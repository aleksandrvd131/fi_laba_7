# Лабораторная работа: Структуры данных (АТД)
## Вариант 6

### Описание варианта задания

- **АТД:** Однонаправленный кольцевой список (Singly Circular Linked List)
- **Способ реализации:** Статический массив (Static array) с явными курсорами-индексами (`next`) и пулом свободных узлов (`free_head`)
- **Тип ключа:** Строковый (`char[]` до 63 символов)
- **Тип данных:** Символьный (`char`)

---

### Архитектура и абстракции проекта

В проекте строго соблюден принцип абстракции данных (**АТД**) и паттерн **«Итератор»**:

1. **Модуль `circular_list` (`circular_list.h`, `circular_list.c`)**:
   - Реализует структуру узла `Node` и структуру `CircularList`.
   - Память организована в виде статического массива фиксированной вместимости (`LIST_CAPACITY = 32`).
   - Вместо указателей Си (`*`) используются целочисленные индексы ячеек массива (курсоры).
   - Свободные ячейки связаны в однонаправленный список (`free_head`), что обеспечивает $O(1)$ выделение и освобождение памяти без системных вызовов `malloc`/`free`.
   - Базовые операции:
     - `list_init` — создание пустого объекта;
     - `list_is_empty` — проверка на пустоту;
     - `list_size` — подсчет числа элементов;
     - `list_push_back`, `list_push_front` — добавление элементов;
     - `list_remove_by_key` — удаление элемента по ключу;
     - `list_print_internal` — печать внутреннего представления структуры (весь статический массив, поля `next`, голова списка `head`, голова свободных ячеек `free_head`).

2. **Модуль `iterator` (`iterator.h`, `iterator.c`)**:
   - Предоставляет абстракцию `ListIterator` для безопасного последовательного обхода кольцевого списка без зацикливания.
   - Итератор инкапсулирует счетчик посещенных элементов и текущий узел:
     - `list_iterator_begin` — создание итератора;
     - `iterator_is_valid` — проверка, не завершился ли полный круг обхода;
     - `iterator_next` — переход к следующему узлу;
     - `iterator_get_key`, `iterator_get_value` — получение данных узла;
     - `iterator_swap_data` — абстрактный обмен данными между позициями двух итераторов.
   - **Высокоуровневые операции реализованы СТРОГО через итератор**:
     - `list_print_all` — печать всех элементов АТД в порядке обхода списка через итератор;
     - `list_find_by_key` — поиск значения по ключу через итератор;
     - `list_sort` — сортировка пузырьком через итераторы (без прямого доступа к внутреннему массиву!);
     - `list_insert_sorted` — поиск места вставки через итератор и добавление элемента с сохранением порядка.

3. **Интерактивный интерфейс (`main.c`)**:
   - Консольное меню со всеми требуемыми функциями: добавление, удаление, поиск, сортировка, вывод обоих представлений (логического и физического), демо-данные.

4. **Модульные тесты (`test_list.c`)**:
   - Полное покрытие всех операций АТД и граничных случаев (пустой список, 1 элемент, переполнение массива, удаление из головы/середины/хвоста).

### Сборка и запуск

Сборка всего проекта:
```bash
make
```

Запуск автоматических тестов:
```bash
make test
```

Запуск интерактивного режима:
```bash
make run
# или
./main
```

Проверка на ошибки памяти через Valgrind:
```bash
make valgrind
```

Очистка скомпилированных файлов:
```bash
make clean
```
